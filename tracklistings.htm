This section is for the tracklistings availble on demo tapes here in the Bay Area. Right now, all that are added are Mars and Mystre Early demo tapes. If anyone else has any changes to make or any additions to demo tapes to put on.. please email me. I'll try to make the changes as soon as possible. If anyone wants to add track listings to their demos on here.. go ahead and email them to me and I will add them as soon as I can. I know there are many of you out there that do know certain tracks and know certain labels that I am not aware of. Please with everyone's help, we can get this list as complete as possible and make it a super duper database for everyone to reference to. Thanks!
